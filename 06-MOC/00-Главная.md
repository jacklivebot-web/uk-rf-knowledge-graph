# УК РФ — Граф знаний

> Второй мозг для уголовного права: статьи, понятия, связи, практика

## С чего начать

- [[00-MOC-УК-РФ]] — карта всего кодекса
- [[Общая-часть-MOC]] — принципы, лицо, вина, наказание
- [[Особенная-часть-MOC]] — преступления по главам
- [[Понятия-MOC]] — алфавитный указатель правовых понятий

## Как это устроено

- Каждая **статья** — отдельная заметка с yaml-фронтматтером
- Связи между статьями — через `[[wikilinks]]`
- Понятия (умысел, хищение, рецидив) — отдельные заметки-хабы
- Пленумы ВС — заметки с привязкой к статьям
- Редакции — прямо в заметках статей

## Источники данных

- [[RusLawOD]] — 304K законов, XML-датасет
- [[Russian-Law-MCP]] — SQLite 530 МБ, FTS5-поиск
- [[Law7]] — PostgreSQL + Qdrant, полный пайплайн
- pravo.gov.ru — официальный источник
